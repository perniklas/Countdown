# AI Coding Assistant Instructions

## Project Context
This is a React Vite Single Page Application (SPA). The project is a simple countdown app.

## Core Directives for AI (ChatGPT/Codex)

* **Keep it simple:** Write straightforward, readable, and minimal code.
* **Do not overengineer:** Avoid complex architectures, unnecessary state management, or excessive abstractions. 
* **Perspective:** Remember, it is a countdown app, not a rocket engine! Stick to basic, functional solutions.
* **No Tests:** Tests are NOT necessary. Do not spend time writing unit tests, integration tests, or configuring testing frameworks. Focus solely on the core application code.
